# TCGVault — Weekly KPI Tracker

Fill one row per week. If you only have time to move one number, move
**sessions/day** — it's the binding constraint. Pull the values from Shopify
Analytics (Reports → Sessions / Sales) and `profit_model.py`.

| Metric | Baseline (2026-06-10) | Target | Why it matters |
|---|---|---|---|
| Sessions/day | ~2.5 | ~55 | The constraint. No traffic = no profit, at any conversion. |
| Conversion rate | 2–8% (noisy) | ≥2.5% | Don't let it fall as traffic scales. |
| AOV | ~€48 | ≥€55 | Free-ship threshold + accessory upsell. |
| Blended gross margin % | ~17–19% | ≥25% | Mix shift sealed→accessories. Run `profit_model.py`. |
| Orders/month | ~17 | ~50 | Revenue ÷ AOV. |
| Heroes out of stock | several (ETBs at 0) | 0 | Never advertise dead inventory. |
| Email list size | ~0 | grow weekly | Owned audience = free repeat demand. |
| **Net profit/month** | ~€0 | **€500** | The goal. From `profit_model.py`. |
